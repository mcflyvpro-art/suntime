# Soleil

Lever et coucher du soleil, France. PWA mobile, sans dépendance, hors-ligne.

- Ouvrir `index.html` directement, ou servir le dossier en HTTPS (GitHub Pages) pour l'installer sur l'écran d'accueil.
- Lyon par défaut ; ~130 villes de France + géolocalisation.
- Balayer la courbe ou glisser sur la frise annuelle pour changer de jour.
